# 🌐 Konsol Integrator (Frontend) — API Gateway UMKM

Selamat datang di repositori **Frontend** untuk proyek API Gateway Ekosistem Ekonomi UMKM (Kelompok 7.0).

## 📖 Apa itu Konsol Integrator?

Jika API Gateway diibaratkan sebagai "Mesin" di belakang layar yang mengatur seluruh lalu lintas data antar aplikasi, maka **Konsol Integrator (Frontend)** ini adalah "Layar Dasbor" atau pusat kendalinya.

Aplikasi web ini dibangun menggunakan **React + Vite** dan ditujukan khusus bagi **Operator Tim IT** dan **Auditor Keuangan**. Melalui dasbor ini, pengelola sistem dapat:
- Memantau kesehatan seluruh aplikasi dalam ekosistem (apakah sedang berjalan lancar atau ada yang mati).
- Meninjau sejarah dan jejak lalu lintas data (Log).
- Mendaftarkan atau mengubah alamat aplikasi tanpa harus mematikan sistem (Route Registry).
- Melihat grafik pendapatan dari pajak layanan integrasi sebesar 0.5% (Gateway Fees).

*Penting: Aplikasi frontend ini TIDAK ditujukan untuk pembeli atau penjual UMKM. Ini adalah alat bantu khusus bagi administrator (di balik layar).*
